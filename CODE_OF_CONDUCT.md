# Código de conducta

## Compromiso

Para mantener una comunidad abierta y profesional, quienes participen en este
proyecto se comprometen a tratarse con respeto, asumir buena fe y colaborar
para resolver desacuerdos técnicos sin ataques personales.

## Conductas esperadas

- comunicación clara, inclusiva y centrada en el problema;
- revisión técnica basada en evidencia;
- bienvenida a preguntas y niveles distintos de experiencia;
- aceptación de correcciones y límites de seguridad;
- protección de credenciales, datos personales y privacidad de terceros.

## Conductas no aceptables

- acoso, insultos, amenazas o discriminación;
- publicación deliberada de secretos, datos de compradores o información de
  infraestructura;
- pruebas contra sistemas sin autorización;
- suplantación, spam o interrupción intencional del proyecto;
- intentar eludir controles de autenticación o aislamiento.

## Aplicación

Un reporte de comportamiento puede abrirse de forma privada mediante el perfil
de mantenedores del repositorio o solicitarse en un issue sin incluir detalles
sensibles. Para vulnerabilidades técnicas usa exclusivamente el proceso de
[SECURITY.md](SECURITY.md). Los mantenedores pueden editar, cerrar o retirar
contribuciones que incumplan este código y explicarán la decisión cuando sea
posible.

Este código se inspira en el Contributor Covenant y se aplica a issues,
pull requests, revisiones, documentación, chats y cualquier otro espacio del
proyecto.
